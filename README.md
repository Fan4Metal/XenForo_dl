# XenForo Thread Image Downloader

Расширение для Chrome (и других браузеров на Chromium), которое скачивает все изображения и видео из открытого треда форума на XenForo 2.x / 1.x — со всех страниц треда.

## Установка

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика** (переключатель справа вверху).
3. Нажмите **Загрузить распакованное расширение** и выберите эту папку.
4. Закрепите иконку расширения на панели (значок пазла → булавка).

## Использование

1. Откройте любую страницу треда (если нужны вложения, сначала войдите на форум).
2. Нажмите на иконку → выберите диапазон страниц → **Сканировать**.
3. Отметьте, что качать: вложения, встроенные/внешние картинки, видео, файлы из цитат и подписей. Мелкие картинки (смайлы, иконки, кнопки) отсеиваются фильтром «Пропускать мелкие» — по умолчанию меньше 100 px по любой стороне.
4. **Скачать**. Файлы сохраняются в `Загрузки/XenForo/<название треда> [id]/` с номерами `001_`, `002_`… в порядке появления в треде.

Окно расширения можно закрыть: сканирование продолжится во вкладке, а загрузка — в фоне. Прогресс будет виден при следующем открытии.

## Что собирается

- полноразмерные вложения (`/attachments/…`), даже если в посте показана только миниатюра;
- встроенные `[IMG]`-картинки (через прокси форума `proxy.php`, в настройках можно включить загрузку напрямую);
- картинки-миниатюры, ведущие по ссылке на полный файл изображения;
- картинки с отложенной загрузкой (`data-src`);
- видео: видео-вложения XenForo (`<video>`), видеофайлы из списка вложений и прямые ссылки на `.mp4`, `.webm`, `.mov` и т.п.

Пропускаются: смайлы, эмодзи, аватары, реакции, превью ссылок, вложения, которые не являются изображениями или видео (zip, pdf…), ролики YouTube и других сервисов из `[MEDIA]` (их нельзя скачать как файл). Дубликаты удаляются.

### Фильтр мелких картинок

Смайлы часто вставляют в посты как обычный `[IMG]`, поэтому по разметке их не отличить от фото. При сканировании расширение узнаёт реальные размеры каждой картинки: на текущей странице они уже известны, для остальных браузер читает только заголовок файла и обрывает загрузку. Если размер узнать не удалось (сайт недоступен), картинка не отсеивается. Порог можно менять после сканирования, счётчики пересчитываются сразу.

## Файлы

| Файл | Назначение |
|---|---|
| `manifest.json` | манифест (Manifest V3) |
| `content.js` | сканер: определяет пагинацию, загружает страницы треда, извлекает изображения |
| `background.js` | очередь загрузок: имена файлов, повторы, отмена, отказ от HTML вместо картинки, восстановление после перезапуска воркера |
| `filter.js` | общие правила фильтрации для popup и фоновой очереди |
| `popup.html/.css/.js` | интерфейс |
| `icons/` | иконки |

## Примечания

- Чтобы не создавать нагрузку на форум, страницы загружаются по 2 одновременно с паузой 300 мс (меняется в настройках). Если форум отвечает 429 или 5xx, запрос повторяется.
- Сетевые сбои повторяются до 3 раз; постоянные ошибки (404, 403, 401) не повторяются. Кнопка **Повторить ошибки** запускает повтор вручную.
- Пока идёт загрузка, раз в 30 секунд срабатывает сторож (`chrome.alarms`): если фоновый процесс расширения перезапускался и пропустил событие, очередь продолжится сама.
- Если вместо изображения сервер вернул HTML-страницу (например, просит войти), загрузка отменяется и попадает в список ошибок.
- Если в настройках Chrome включено «Всегда указывать место для скачивания», расширение всё равно сохраняет файлы без диалога.
